# Восточный Торгмортранс — сайт

Одностраничный сайт ООО «Восточный Торгмортранс» (п. Врангель, Находка): услуги, техника, информация о компании, лицензии, партнёры, FAQ, форма заявки и карта.

Чистый HTML + CSS + JavaScript — без сборки и зависимостей.

## Структура

```
index.html            — вся страница
assets/css/styles.css — анимации, ховеры, адаптив
assets/js/main.js     — заставка, FAQ, просмотр лицензий, форма заявки
assets/img/           — фотографии, логотип, логотипы партнёров, сканы лицензий
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки (файл `index.html` должен лежать в корне).
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Свой домен (например, `tmt-vost.ru`): в том же разделе **Pages → Custom domain** укажите домен, а у регистратора добавьте DNS-записи, которые покажет GitHub.

## Что нужно донастроить

- **Форма заявки.** Без сервера кнопка «Отправить заявку» открывает почтовую программу посетителя с готовым письмом на `tmt@tmt-vost.ru`. Чтобы заявки приходили на почту напрямую, зарегистрируйте форму в сервисе вроде [Formspree](https://formspree.io) и вставьте её адрес в `FORM_ENDPOINT` в начале блока «Lead form» в `assets/js/main.js`.
- **Telegram.** Ссылка на Telegram пока пустая: замените `href="#" data-todo="telegram"` в `index.html` на адрес канала или аккаунта компании. WhatsApp уже ведёт на номер 8 (4236) 668-085.
- **Логотип с якорем** в блоке партнёров подписан как «Партнёр компании» — укажите название в атрибуте `alt` файла `assets/img/partners/partner.jpg`.
- **Политика конфиденциальности.** Ссылка в подвале пока ведёт на раздел контактов: добавьте страницу с политикой и поставьте ссылку на неё.

## Локальный просмотр

Откройте `index.html` в браузере. Карта Яндекса и шрифты Google загружаются из интернета.
